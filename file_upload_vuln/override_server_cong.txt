in an IIS server (which is a server built by microsoft to host website and handle http requests) directory specific configuration is usually allowed.
a configuration file can be used to set which MIME type is allowed in a particular directory.

example:
<staticContent>
    <mimeMap fileExtension=".json" mimeType="application/json" />
    </staticContent>

changing the fileExtension to .php will allow php file to be uploaded. although config files are off limits, but u might be allowed to upload your own configuration file.
