php is a loosely typed langauage which means it supports operations between two different data type.

Variables
Every variables in php begins with a dollar ($) sign and every statement ends with a semi-colon
var_dump() function is used to check the data type of a variable

we use the static keyword to declare local scope variable that we do not want to be deleted.
we use thhe global keyword to access a global variable from inside a local environment
when a variable is declared with the ampersand synmbol in a local environment then it acts like a global variable. the paramter is passed by reference making any edit done to the variable in the local function to be reflected in the original variable.

Operators
They are synmbols used to perform operations on Variables. They can be:
Arithemetic Operators: +, *, /, -. %, **
Assignment Operators: +=, -=, *=, /=, %=, =
Comparison Operators: ==, === (equal and have the same datatype) etc
Increament Operators: x++ (returns x first then increament it by 1), ++x (increament x by 1 then returns it), --x, x--
Logical Operators: AND, &&, ||, OR, XOR, NOT etc
String Operators: ., .= (appending assignment)
